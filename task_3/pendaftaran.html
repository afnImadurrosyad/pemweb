Formulir Pendaftaran

Daftar sebagai peserta seminar

Isi data diri pada formulir di samping. Setelah tombol Kirim Pendaftaran ditekan, browser akan meneruskan data ke halaman detail pendaftar melalui query string pada URL (method GET).

Alur pengiriman data

  1. Peserta mengisi formulir pendaftaran.
  2. Browser menyusun pasangan name=value dari setiap kontrol form.
  3. Data dikirim ke detail.html sebagai query string, contoh: detail.html?nama=Afnan+Imadurrosyad&nim=124140125&prodi=Informatika
  4. Halaman detail menampilkan informasi pendaftar (data dummy pada tugas ini).
